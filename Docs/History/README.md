# RelayBar 0.5 documentation

Start with **../START_HERE.md** for installation and Context Stack use.

The current implementation notes and results are in **ContextStack/DESIGN.md** and **ContextStack/VALIDATION.md**. **ContextStack/PROVENANCE.json** identifies both actual input archives, the unchanged native foundations, and the exact automatic Sheets extension.

All versioned earlier receipts, acceptance guides, source references and tests marked historical describe those earlier releases, not validation of the new native feature. `../RelayBar_Preview.html` remains the historical text-workflow browser preview; it is not a Context Stack preview, native installer, or proof of physical Touch Bar behavior. Historical AppsScript files are not required for the current automatic Sheets setup.

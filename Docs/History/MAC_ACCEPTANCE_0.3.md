# Real-device acceptance — NOT run here

Record your macOS version, browser/version and installed RelayBar version. Use a copied workbook and harmless no-argument functions, such as a toast or an empty dialog. Do not start with deletion, bulk updates or outgoing messages.

1. Quit the app and disable any RelayBar extension; let prior installers finish. Run Install.command. Confirm it reports the 0.3 app installed, its prior app backup, and no compiler/signing error. Run Doctor.command and Screenshot_Test.command. A parser pass from Linux is not sufficient.
2. Launch the app. Verify cross-app mode starts OFF, app-aware layouts ON, screenshot auto-open ON (unless you previously changed it), and prior screenshots/settings/projects remain. Re-enable cross-app mode. Switch native ChatGPT → Claude → Finder. Verify assistant layouts follow, Finder retains its native bar, and a composed draft is not silently redirected.
3. Run Set_Up_Sheets.command. Load the stable extension folder, register the exact ID, enable the extension, and verify its popup says the native link is connected. A wrong ID/missing host must fail cleanly without requesting a key or public deployment. Run registration in each other browser you intend to use; none have been verified here.
4. Add the two new files to a copied workbook’s existing bound project; preserve its existing onOpen and scopes. Verify connection does not execute a script or modify cells. Confirm a drawing with an assigned function and an image with an assigned function are discovered. Confirm custom menus are absent until explicitly registered.
5. Register at least six harmless actions. Confirm four per Touch Bar page and correct next/previous behavior; labels and confirmation settings must match the sidebar. Verify an action from another worksheet refuses execution until you switch there. Long labels may be shortened on the bar; confirm full labels in the sidebar.
6. Tap a default action: it must wait for sidebar confirmation. Cancel, then confirm a fresh tap and verify exactly one execution. Register one harmless `confirm:false` action and verify one tap executes it. Try a function opening a modal dialog. A function replacing the sidebar must disconnect RelayBar until reopened.
7. Open two copies of the workbook in browser tabs and a different workbook. Rapidly switch tabs/windows/apps before tapping. Old buttons must not run in the new context. Background windows, private windows and stale/disconnected sidebars must not remain actionable. Test duplicate rapid taps and disconnect during confirmation. No automatic retries should occur.
8. Switch Sheets → a generic browser page → ChatGPT web → Sheets. Verify profiles, navigation buttons and the correct Sheet’s actions. Closing the sidebar must remove its actions. Disabling the extension must remove actionability within the freshness window; disabling app-aware layouts must cancel queued taps and restore the original AI layout in supported apps.
9. While Sheets is linked, take screenshots normally. The shelf must open without activating RelayBar, paste or send. Tap an image and paste manually, then use Sheets to return to that Sheet’s controls. A brief browser reconnect should not dismiss the shelf; a real tab/app change should restore the new context. Repeat in ChatGPT. Verify five images and originals unchanged.
10. Relaunch the app/browser; verify fresh link sessions, no old command replay and cross-app mode still OFF until enabled. Confirm extension-off stops metadata receipts. Disable/remove the extension before app upgrade/uninstall, and verify unrelated project/screenshot originals are retained.

Live Google authorization, Apps Script V8 function resolution, HTML-service iframe matching, native host launching and physical Touch Bar timing remain the highest-priority unverified seams. Report the actual failing step and log rather than treating the portable tests as their substitute.
